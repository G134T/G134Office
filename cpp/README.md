# G134Office Lite 0.2

Текстовый редактор для Windows: один exe, Win32, без JVM и JavaFX. Документы docx и pdf он не открывает — для них есть основное приложение [G134Office](https://github.com/G134T/G134Office).

## Что умеет

- Новый файл, открытие, сохранение и «сохранить как». Запись идёт во временный файл и затем заменяет исходный.
- Кодировки: UTF-8, UTF-8 с BOM, UTF-16 LE, UTF-16 BE и Windows-1251. Исходные концы строк (CRLF, LF или CR) сохраняются. В Windows-1251 символ, которого нет в этой кодировке, не подменяется знаком «?»: сохранение отменяется.
- Перетаскивание файла в окно и открытие пути из командной строки.
- Поиск вперёд и назад, замена одного и всех вхождений. Замена всех вхождений — одно действие «Отменить».
- Переход к строке, перенос строк, шрифт, масштаб 8–72 pt, тёмная тема. При включённом режиме высокой контрастности Windows свои цвета не подставляются.
- Строка состояния: строка, столбец, слова, знаки, кодировка, концы строк, кегль.
- Список недавних файлов (до 8) и положение окна. Они лежат в `%LOCALAPPDATA%\G134Office`, а не рядом с exe.
- Файлы больше 8 МБ не открываются. Нулевые байты в тексте, кроме обычного UTF-16, вызывают вопрос, открывать ли файл.

## Сборка

Нужны CMake 3.20+ и Visual Studio с компилятором C++ (x64):

```powershell
cmake -S cpp -B cpp/build -A x64
cmake --build cpp/build --config Release
cpp\build\Release\lite_tests.exe
cpp\build\Release\G134OfficeLite.exe
```

`lite_tests.exe` проверяет кодировки, поиск и статистику и печатает `ok`. Каталог `cpp/build` в репозиторий не входит.

На GitHub Actions сборка запускается при изменении `cpp/**` и выкладывает `G134OfficeLite.exe` артефактом. Тот же exe входит в обычный установщик `G134Office-Setup`: при установке выбирается полная версия или облегчённая. Отдельный артефакт сборки Lite подписью установщика не является.

## Страница в браузере

`cpp/web/index.html` — отдельный редактор в браузере. Счётчики текста считает `cpp/web/wasm/lite_core.cpp`; сборка WebAssembly и публикация страницы идут своим сценарием и не заменяются этим exe. Кодировки, недавние файлы и запись через временный файл есть только в программе Windows.
